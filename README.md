# Rd. Note map data

iOS アプリ「Rd. Note」が走行後の道路の照合に使う地図データ(Valhalla のタイル)と、道路名のデータの配布元です。
ファイルは Releases に回ごとに置き、アプリは設定 → 地図データから利用者が選んだときだけ取得します。

---

Map data (Valhalla routing tiles and road-name data) used by the iOS app Rd. Note for post-drive map matching.
Files are published as Releases and are downloaded only when the user chooses a region in Settings → Map data.

Data © OpenStreetMap contributors, available under the Open Database License (ODbL) 1.0.
